# NetworkService

A lightweight and generic Swift Package to perform RESTful `GET` requests using `async/await`. Compatible with **iOS 15+**.

## Features

- Generic support for any `Decodable` type
- Custom error handling with detailed error descriptions
- Lightweight and easy to integrate
- Written in pure Swift with no external dependencies

---

## Requirements

- iOS 15+
- Swift 5.5+

---

## Installation

Use [Swift Package Manager](https://swift.org/package-manager/) to install:

1. In Xcode, go to `File` > `Add Packages...`
2. Enter the repository URL: `https://github.com/xippie/NetworkManager.git`
3. Choose the version you want to install.
